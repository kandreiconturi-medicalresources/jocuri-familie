# Jocuri Familie

Jocuri pentru copii și părinți, care merg pe telefon, tabletă și calculator:

- **Aventura lui Bobo și Mimi**: platformer pentru 1–2 jucători
- **Bum-Bum Arena**: în curând
- **Turbo Curse**: în curând
- **Orășelul**: în curând

## Cum instalezi jocul ca aplicație

**Link:** https://kandreiconturi-medicalresources.github.io/jocuri-familie/

- **iPhone / iPad:** deschide linkul în **Safari**, apasă **Partajare** (pătratul cu săgeată), apoi **Adaugă pe ecranul principal**. Jocul pornește pe tot ecranul și merge și fără internet.
- **Android:** deschide linkul în Chrome, apoi meniul ⋮ → **Instalează aplicația**.
- **Calculator:** deschide linkul în Chrome sau Edge și apasă iconița de instalare din bara de adrese.

Trimite **linkul**, nu fișierul: pe iOS, Signal nu rulează fișierele `.html`.

## Pentru dezvoltare

```
npm install
npm run dev     # server local
npm test
npm run build   # rezultatul ajunge în dist/
```
